# AgroConnect 🚜🌱

Plataforma integral diseñada para empoderar a los productores del campo, conectando el talento rural con oportunidades laborales y comerciales, integrando gestión inteligente con IA y academia de saberes locales.

## 🏗️ Arquitectura del Software

Este proyecto está organizado siguiendo una **Arquitectura de Capas Limpias (Clean Layers)** para garantizar el orden y la escalabilidad:

- **`src/pages/`**: Vistas principales de la aplicación.
- **`src/components/`**: Componentes reutilizables.
- **`src/services/`**: Lógica de acceso a datos y simulaciones (Mock API).
- **`src/types/`**: Definiciones de interfaces de TypeScript para consistencia de datos.
- **`src/assets/`**: Estilos globales y activos multimedia.
- **`src/hooks/`**: Lógica personalizada reutilizable.

## 🛠️ Tecnologías

- **Frontend**: React.js + TypeScript
- **Bundler**: Vite
- **Navegación**: React Router v6
- **Iconografía**: Lucide React
- **Estética**: Vanilla CSS (Custom Design)

## 🚀 Instalación y Desarrollo

1. Clonar el repositorio.
2. Instalar dependencias:
   ```bash
   npm install
   ```
3. Ejecutar en modo desarrollo:
   ```bash
   npm run dev
   ```
